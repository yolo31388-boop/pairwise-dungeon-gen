# pairwise-dungeon-gen

随机关卡一跑，玩家就卡在封闭房间里：地牢生成先放房间再连走廊，走廊端点没有对齐门，门被墙堵死；BSP 切分只按面积，长条房间把地图撑出边界；种子只用了时间，回放和每日挑战对不上；房间重叠检测用包围盒，L 形房间斜角重叠没发现；连通性只检查房间中心，走廊中间断开也算通；生成失败没有重试上限，偶尔死循环。game/dungeon_gen.py 是核心，tests/test_dungeon_gen.py 15个红。要修的是：房间和门对齐；BSP 加长宽约束；种子确定性；L 形精确重叠；全格子 flood fill 连通；失败重试上限。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
